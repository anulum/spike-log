# Governance

Miroslav Šotek, ANULUM, owns the project and its licensing and publication decisions. Maintainers review repository changes, source provenance and acceptance evidence. Local validation does not authorise a release, service change, signing operation, key use or scientific qualification.

Evidence-schema ownership is explicit. A planned identifier is neither registered nor supported. Consumer compatibility and independent verification require real implementation and reviewed conformance evidence. A local diagnostic report cannot transfer another producer's ownership or authority.

Contract changes require affected review, matching implementation and genuine public-boundary evidence. Security decisions use a separate eligible reviewer. Publication and deployment have their own concrete approval and verification boundaries.
