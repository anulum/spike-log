# Security

Report suspected vulnerabilities privately to protoscience@anulum.li or [ANULUM contact](https://anulum.li/contact.html). Include a finite safe reproduction, affected command and source/lock identity. Do not publish credentials, keys, private recordings or personal data.

Current supported scope is Linux local repository validation with the locked Python 3.13 environment. Diagnostic output is bounded and contains fixed authored reasons. Missing tooling, incomplete scans, interruptions and invalid provenance refuse acceptance. See [the threat model](docs/THREAT_MODEL.md) for residual risks and process ownership.

There is no released signer, key store or deployed verification service. This repository makes no security certification or scientific qualification claim.
